## ✨ 這個模組在做什麼？

原版的經濟、家族與王國，很多地方只能「看著它發生」。**家鄉祝福**把這些環節接成完整的循環，並交給你掌控：

> 養大村莊人口 → 把糧食送進城鎮 → 城鎮繁榮 → 用繁榮養出更強的家族與部隊 → 站穩王國

大部分功能設定一次就會自動運作，也都能獨立開關，只用你喜歡的部分就好。

---

## 🌾 城鎮繁榮循環

多餘的士兵與俘虜不再是負擔，可以直接送回村莊變成人口。

- **人力市場**：兵與俘虜換成村莊戶數
- **氏族糧運／貿易綁定**：決定貨物與糧食往哪座城鎮送
- **村民救援**：村莊被攻擊時，家族部隊自動馳援
- **定居點自動建造**：自動蓋好住宅與糧倉
- **城鎮經濟主控台**：一眼看出哪座城鎮缺哪類食物

## ⚔️ 戰場強化

從單挑到千軍萬馬，每個功能都有獨立開關。

- **戰鬥回血**、**攻擊橫掃**、**跑動格擋**：強化你自己
- **棄盾**、**敵軍無馬／無盾**：削弱敵人
- **戰場不撤退**：部隊不會無故潰逃
- **分身術**（按 `H`）：召喚分身助陣，擊殺達標還能再叫一組
- **蓄力劍氣波**、**即時圍攻**：範圍清場與快速攻城

## 🛡️ 家族與部隊管理

按 `F4` 開啟儀表板，一個畫面管理所有家族部隊。

- **士兵倉庫**：進城自動存精銳、離城自動補兵
- **軍團管理**：建立軍團、維持凝聚力、集結部隊
- **批量重配備**：用規則一次分配好同伴裝備
- **巡邏跟隨、馳援部隊**：一鍵調度家族部隊

## 👑 王國政治

- **王室特權**：力邀群雄、封地收回、慷慨令、四分五裂等
- **推杯換盞**：奪取王位
- **家族與王國重整**：創建家族、王國合併、自動分家
- **稅收與影響力**：領地富翁稅、村莊定期收購、每週影響力發放

## 🍺 招募與活動

- 酒館傭兵、傭兵團、藏身處劫匪、俘虜轉募兵，多種兵源
- 酒館日常任務與說服領主俘虜
- 自家城鎮錦標賽，可以指定同伴當冠軍

## 📈 角色成長

- 技能學習上限解除、自訂學習曲線
- 魅力、工程、戰術經驗共享
- 自動分配技能、同伴特質重骰、鍛造強化

## 🧩 模組組成

模組採拆分設計，可以只安裝需要的部分。

| 模組 | 內容 |
|---|---|
| **HometownBlessings**（核心） | 繁榮循環、家族與部隊、王國政治、招募與任務 |
| **HometownBlessingsCombat** | 戰場強化 |
| **HometownBlessingsOverhaul** | 15 項開關式的玩法調整（部隊上限、懷孕、忠誠度、鍛造等） |
| **HometownBlessingsRecruitment** | 傭兵與劫匪招募 |
| **HometownBlessingsTournament** | 錦標賽操控 |
| **HometownBlessingsUnlimitedLearning** | 技能無上限學習 |

## 🎮 快速上手

| 熱鍵 | 功能 |
|---|---|
| `F4` | 戰術選單與家族部隊管理 |
| `Ctrl+O` | 後勤選單（戰場內為切換同伴） |
| `F` | 快速記憶指令 |
| `H` | 戰場內召喚分身 |
| `Ctrl+U` | 同伴列表篩選 |

進入城鎮後，從選單 **「家鄉祝福」** 開始探索。
