## 原版：王國大多交給 AI 與規則決定

原版裡，王國是「一群人共同經營」的組織：外交、封地、政策多半由 AI 領主投票與固定規則決定。你就算當上國王，能直接動用的手段也有限——影響力常常不夠用、家族數量失衡你插不上手、領地分配不如意、稅收與金流也調不動。

這個模組把王國層級的操作整理成幾個方向：**累積影響力 → 做出王國決策 → 奪取權力 → 重整家族與版圖 → 調整領地與稅收 → 對外宣戰**。其中一部分是選單裡的手動操作，另一部分是每日、每週自動運作的發放與結算。

## 累積影響力

### 每週王國影響力發放

每 **7 天**，對**所有存活王國**中影響力偏低（低於 700）的合格家族發放一次影響力：國王固定一筆，封臣依家族等級遞增。**預設開啟**。

要注意的是，這是**平衡世界的機制**：玩家自己的家族被排除在發放之外。它的作用是讓全地圖的王國不至於因為影響力枯竭而癱瘓——你會在背景看到各國慢慢恢復元氣。

開關由核心模組提供，介面掛在大修設定的「王國與領地」分類（需大修模組）。

### 影響力販售

影響力不夠用時的出口。**1 點影響力換 50 第納爾**，錢從王國內**其他城鎮的金庫**支付（繁榮度高的城鎮優先），而賣出的影響力會**轉給那些城鎮的家族**。

入口：Ctrl+O 後勤選單 →「影響力販售」。

## 王國決策：王室特權

**入口：「家鄉的祝福」→「王室特權」。** 多數項目需要你是國王才能使用。

| 特權 | 做什麼 |
|---|---|
| 力邀群雄 | 花費金幣，邀請**沒有領地**的家族加入你的王國（費用依家族等級） |
| 封地收回 | 收回王國內其他家族的城鎮／城堡歸你，需花影響力、付補償金，並扣你與該家族領袖的關係 |
| 振興王國 | 把一筆金幣**平均分給王國內所有家族** |
| 威權下放 | 把一筆影響力**平均分給王國內所有家族** |
| 養虎為患（金錢） | 把金幣分配給**指定國家**的家族（扶植對手的一種玩法） |
| 養虎為患（影響力） | 同上，改為分配影響力 |
| 慷慨令 | 每日自動分配影響力或金錢給王國內其他家族（見下） |
| 四分五裂 | 把王國分裂成多個小王國 |

### 慷慨令

王室特權中唯一會**持續運作**的項目，分兩個獨立開關：

- **慷慨令（影響力）**：每日把你**影響力的 20%** 平均分給王國內其他家族。開啟前提：你是王國成員且**影響力超過 3,000**。
- **慷慨令（金錢）**：每日把你**收入的 20%** 平均分給王國內其他家族。開啟前提：**金錢超過 1,000,000**。

家族財務與政治模型會把慷慨令的收支算進你的預估，所以家族畫面的數字會反映實際金流。

## 奪取權力：推杯換盞

**入口：「家鄉的祝福」主選單。**

當你在王國內的**影響力超過其他所有家族的總和**時，可以消耗**全部影響力**登上王位。它是獨立的入口，不在王室特權之中。

## 重整家族與版圖（「王國平衡」選單）

| 功能 | 做什麼 | 說明 |
|---|---|---|
| 家族擴張平衡 | 為人口偏少的家族補充領主 | 可**手動**（依王國／文化篩選，選人數門檻 3／5／7／11／20）或**自動平衡**（為活躍英雄 ≤3 的家族補到 3 人） |
| 創建新家族 | 在指定王國建立數個新家族 | 由該文化的既有英雄生成新領主 |
| 王國合併 | 選一個主要王國，把其他王國併入 | 以王國國力排序供選擇 |
| 四分五裂 | 分裂王國 | 入口在王室特權 |

### 家族溢出分家

AI 家族過大時**自動分家**，避免一國獨大。每日結算，英雄成年時也會觸發。可在**大修設定**開關並設定家族數量上限（預設 30，可調 15～50）。

## 領地結構（大修模組）

以下由大修模組提供，在「大修設定」開關：

| 功能 | 觸發 | 作用 |
|---|---|---|
| 封地再分配 | 攻城結算後 | 重新分配剛攻下的領地 |
| 封建稅收再分配 | 每日 | 重新分配封建稅收 |
| 沒有流浪家族 | 王國滅亡後 | 收容無家可歸的家族，避免其消失 |
| 禁止掠奪玩家領地 | AI 選擇目標時 | AI 不把玩家領地列為掠奪目標 |
| 城鎮忠誠度加成 | 每日 | 提高城鎮忠誠，更穩、更會生錢（在「經濟與經營」分類） |
| 靈活軍團管理 | 組織／徵召／資格查核時 | 放寬軍團規則（在「軍隊與戰鬥」分類） |

## 稅收與金流

### 領地富翁稅

每日結算，**條件是「你擁有王國內最多的領地」**（城鎮權重高於城堡，且為唯一最高）。一旦成立，系統會把你身上**一部分金錢分給王國內其他家族**——用意是「你地最多，就多分一點給大家」，是一種反向的財富平衡。

可在「稅收」選單開關並設定稅率（預設 1%）。

### 王國村莊定期收購

每 **3～21 天（預設 3 天）**，各王國把村莊的貨整批買回城鎮市場，並**依城鎮繁榮度分配**。這是王國層級的功能，**AI 王國也會執行**。它與 城鎮繁榮循環 的貨物流動相連。

入口：「村莊與領地 → 村莊定期收購」。

### 家族財務與政治模型

被動功能，讓慷慨令、村莊收購等金流正確反映在家族財務預估與政治影響力計算中。

## 外交與軍事：為戰而戰

**入口：F4 →「為戰而戰」。** 需先加入一個王國；接著挑一個王國宣戰（清單依「與你最高繁榮定居點」的距離排序）。沒有額外成本或投票。

## AI 領主 vs 你

- **AI 與系統自動在做**：每週影響力發放、家族溢出分家、封地與稅收再分配、村莊定期收購。世界的版圖與金流會**自己流動**，不會永遠一國獨大。
- **你要自己下決定**：要不要用王室特權、慷慨令開哪一種、富翁稅稅率、家族上限、以及什麼時候宣戰。

## 風險與取捨

- **慷慨令是「花自己的」**：它會持續把你的影響力／金錢分出去，適合你資源充裕、想提升王國整體時開；缺資源時別開。
- **封地收回會扣關係**：想收地就得付影響力、補償金，還會傷與原領主的關係，收回前先想清楚值不值得。
- **領地富翁稅是反向的**：它針對「地最多的你」課金分給別人，不是替你加稅收。
- **影響力販售有連帶效果**：賣出的影響力會流向城鎮家族，等於同時扶植了別人。

## 建議的搭配

1. **剛稱王、王國虛弱**：用**振興王國**（分金）＋**威權下放**（分影響力）幫家族補血，再開**每週影響力發放**讓世界回穩。
2. **想集權**：用**封地收回**把關鍵城鎮收回，搭配**推杯換盞**確保王位。
3. **想重塑地圖**：**王國合併**壯大自己、**四分五裂**拆散對手。
4. **想加金流**：**王國村莊定期收購**把貨與金留在體系內，並用**家族財務模型**看實際變化。
