## 原版：家族一大，管理就變成苦差事

原版裡，家族是你的根，部隊是你的拳頭。但當家族成員與部隊一多，管理會迅速失控：每一支部隊要你手動補兵、每一個同伴的裝備要一件件換、軍團凝聚力不盯就會散掉。到了後期，你大半時間不是在打仗，而是在當部隊的會計。

而且原版有天花板：同伴數、部隊數、部隊上限都被家族階級綁死，想擴張只能慢慢熬。

這個模組把管理拆成幾個層次，**大部分交給系統自動跑**：**保管精銳 → 自動調度部隊 → 管理軍團 → 整頓同伴裝備 → 處理人事 → 拉高上限**。你主要的操作入口集中在 **F4 選單**與 **Ctrl+O 後勤選單**。

## 層次一：保管精銳（士兵倉庫）

把高階兵集中保管：**離城時自動補兵、進城時自動存入**。倉庫裡的**低階兵與俘虜還能每週轉化成村莊人力**，接上 城鎮繁榮循環。

預設規則是「存 T5–6、取 T1–4」，離城補兵的單次上限為 3（高階優先）。相關設定在「家鄉祝福自定義 → 士兵倉庫設定」：

- 提領（取出）與存入的階級範圍（T0～T6）
- 每週轉化開關，以及各階級是否轉化（**預設全部關閉**）
- 優先取出的文化，或改選「匪徒」

**士兵收集**：家族部隊進城時，自動把高階兵收進倉庫（敵方正在交戰的定居點不收）。

## 層次二：自動調度（家族部隊管理）

### 家族部隊自動管理

自動幫你**創建家族部隊、整補兵力、配送人力**，觸發時機為部隊建立、每日結算與 AI 每小時結算。

### 家族部隊管理儀表板

**入口：F4 →「家族部隊管理」。** 一個畫面看所有家族部隊，並提供這些操作：

| 按鈕 | 做什麼 |
|---|---|
| 隊伍 | 點選任一支部隊，查看成員、指派職位（斥候／工程／外科／軍需）、補充戰力 |
| 自動創建 | 選擇哪些英雄可以自動建立新部隊 |
| 自動歸建 | 設定部隊的自動歸建清單 |
| 軍團管理 | 進入自訂軍團畫面 |
| 批量重配備 | 進入規則式同伴重配備 |
| 城鎮經濟 | 進入城鎮經濟主控台（需擁有城鎮） |
| 村莊貿易城鎮選擇 | 設定城鎮村莊貿易綁定 |

## 層次三：軍團

### 軍團管理畫面

從儀表板進入，可**建立／解散軍團、管理成員、維持凝聚力、集結部隊**。這個自訂畫面取代了原版「組織軍團／解散軍團」的按鈕。

### 每日凝聚力維持

每日自動幫氏族軍團維持凝聚力，軍團不會因凝聚力耗盡而解散。

## 層次四：同伴裝備

| 功能 | 做什麼 | 入口 |
|---|---|---|
| 批量重配備 | 用規則一次把同伴的裝備分配好 | 儀表板 →「批量重配備」 |
| 防具自動優化 | 自動幫同伴換上更好的防具 | Ctrl+O「同伴篩選」 |
| 進城自動整頓 | 進城時自動做武器升級與防具優化 | 自動 |
| 領主釋放後重配備 | 俘虜領主釋放後自動重新配裝 | 自動 |

**批量重配備**採「規則」制：每條規則可設定**適用範圍、技能條件、要拿哪種手持武器、四個裝備槽、坐騎與自動彈藥**。最多 30 條規則，新存檔會預置兩條範例；套用時只處理**你主部隊裡的英雄**。

## 層次五：人事管理

- **提拔領主**（F4 →「提拔領主」）：把士兵或同伴提拔成家人，也能刷新流浪者名單。
- **領主交易**（地下黑市／城堡）：進行俘虜交易與贖回家族成員。
- **家人同伴匯出／匯入**（地下黑市）：匯出或匯入家人與同伴。
- **同伴改名、同伴篩選**（Ctrl+O）：整理同伴名單。

## 層次六：兵力補充

| 功能 | 做什麼 | 入口 |
|---|---|---|
| 一鍵收取俘虜 | 快速把俘虜收進自己部隊 | 地下黑市 |
| 一鍵購買駐軍 | 直接買下駐軍士兵 | 地下黑市、城堡 |
| 領主對話購買士兵 | 跟領主買兵 | 領主對話 |

## 移動與指揮

| 功能 | 做什麼 | 熱鍵 |
|---|---|---|
| 部隊巡邏跟隨 | 讓家族部隊跟著你或巡邏 | F4 |
| 馳援部隊 | 傳送至某支家族部隊身邊 | F4 |
| 快速記憶指令 | 對你追蹤的目標（或正被敵國掠奪的村莊）用記住的指令快速派兵 | F |

## 大修模組：上限與存活（被動）

大修模組中與家族／部隊相關的功能都是被動加成，在「大修設定」開關：

| 分類 | 功能 | 作用 |
|---|---|---|
| 上限 | 部隊上限加成 | 提高部隊人數上限（0 關／1 僅玩家／2 全部） |
| 上限 | 家族部隊擴張 | 提高同伴與部隊數上限（0 關／1 僅玩家／2 含 NPC） |
| 存活 | 隊伍速度加成 | 部隊移動更快 |
| 存活 | 治療量加成 | 每日治療更多傷兵 |
| 升級 | 保留劫匪文化升級 | AI 自動升級家族部隊時保留劫匪文化 |
| 家族 | 聯姻加入家族 | 聯姻對象直接加入你的家族 |
| 家族 | 懷孕強化 | 調整懷孕相關參數 |
| 家族 | 加速兒童成長 | 兒童長大更快，成長倍率可設定 |
| 家族 | 同伴特質重骰 | 同伴加入時重骰人格特質 |

## AI 領主 vs 你

- **AI 領主自動在做**：家族部隊自動管理、每日軍團凝聚力。所以各國領主的部隊會一直維持在健康狀態。
- **你要自己在儀表板決定**：要把哪些英雄設為自動創建、自動歸建清單、同伴重配備規則、以及什麼時候提拔誰。
- **一鍵類功能只服務你**：收取俘虜、購買駐軍、提拔領主等，都是你的專屬操作。

## 風險與取捨

- **自動化要設對**：自動創建／歸建若設太寬，家族會冒出一堆部隊吃你的資源；建議先小範圍試。
- **士兵倉庫的階級範圍是關鍵**：存太低會把要用的兵收走；轉化開關則會把兵變成村莊人口，和「留著當戰力」互相排擠。
- **批量重配備是規則制**：規則條件設錯，同伴可能換上不合手的裝備；新檔預置的兩條規則是安全起點。

## 建議的搭配

1. **開局先顧精銳**：設好**士兵倉庫**階級範圍，配合**士兵收集**，家族部隊進城自動存高階兵。
2. **不想手動管部隊**：在**儀表板**設定自動創建與自動歸建清單，之後交給**家族部隊自動管理**。
3. **同伴一次搞定**：出城前用**批量重配備**＋**同伴篩選**，人人一套好裝。
4. **想擴張家族**：大修模組的**家族部隊擴張**＋**聯姻加入家族**＋**加速兒童成長**。
